# Amber — Phone-Capable Voice Agent

Give OpenClaw agents a real phone line with a Twilio/OpenAI Realtime bridge, inbound call screening, confirmed outbound calls, local call logs, optional local CRM memory, calendar booking, contacts lookup, MCP tools, and a localhost dashboard.

## Highlights

- Answer and screen incoming calls with configurable greetings and escalation rules.
- Prepare outbound calls by prompt, then require an explicit confirmation before dialing.
- Review local call logs, transcripts, captured messages, and estimated costs in the dashboard.
- Start localhost test calls from the dashboard and choose regular or mini Realtime per call.
- Optionally enable local CRM/contact memory and calendar booking with disclosed privacy boundaries.

## Safety Notes

Amber handles sensitive communications. Operators should configure caller notice/consent, retention/deletion practices, least-privilege Twilio/OpenAI credentials, and payment/escalation rules before production use.
